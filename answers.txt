Question: 14) Write a high-level pseudocode (or code outline) for a function that parses the long SDG text and returns a dictionary mapping each goal number to a list of its targets with their codes and descriptions.
Answer: Here’s a high-level Python-like outline you can adapt. It returns a dictionary mapping each goal number to a list of targets, where each target has a code (e.g., "Target 1.1") and a description (string).

Algorithm outline (pseudo-code)

- Function parse_sdg_text(text):
  - Input: text string containing the full SDG resource document
  - Output: dict<int, list of {code: string, description: string}>

  - Initialize result as empty dict
  - Set current_goal to None
  - Split text into lines: lines = text.splitlines()
  - For each line index i from 0 to len(lines)-1:
    - line = lines[i].strip()

    - If line matches goal header pattern, e.g. "Goal <n>.":
      - Extract n as integer
      - current_goal = n
      - If current_goal not in result, set result[current_goal] = []
      - Continue to next line

    - If line matches target line pattern, e.g. "Target <code> <description>":
      - Extract target_code_part (e.g., "1.1", "11.a") and the initial description text
      - code = "Target " + target_code_part
      - description = initial description text (trim)
      - Create target_entry = { "code": code, "description": description }
      - If current_goal is not None, append target_entry to result[current_goal]
      - Now collect continuation lines that belong to this target:
        - Move to next line index j = i + 1
        - While j < len(lines):
          - cont = lines[j].strip()
          - If cont is empty, skip or append as space
          - If cont starts a new target or a new goal (matches r"^(Target|Goal)\s+"), then break
          - Append cont to target_entry["description"] with a space
          - j += 1
        - Set i = j - 1 (to continue from the last consumed line)
      - Continue to next iteration

    - Otherwise: ignore or handle as stray text (the algorithm focuses on Goal/Target lines)

  - Return result

Notes and implementation tips

- Goal detection: use a regex like ^Goal\s+(\d+)\. to capture the numeric goal.
- Target detection: use a regex like ^Target\s+(\d+(?:\.\w+)?)\s*(.*)$ to capture codes such as 1.1, 2.3, 11.a, etc., and the initial description.
- Description assembly: many targets wrap across multiple lines. After recognizing a target, keep appending subsequent non-goal/non-target lines to its description until you hit the next Target or Goal line.
- Data shape: each value in the result is a list of targets for that goal. Each target is a simple dict with:
  - "code": e.g., "Target 1.1"
  - "description": the full description text for that target
- Edge cases:
  - A target line may have no description on the same line; the description may begin on the next line(s). The continuation logic should include such lines.
  - Sub-targets like "Target 11.a" should be treated as targets under the parent Goal 11; the goal number is the top-level key.

Optional enhancements

- Normalize whitespace in descriptions (collapse multiple spaces, trim).
- Optionally store the parent goal as part of each target if you want a faster cross-check.
- Add simple unit tests with representative fragments of the SDG text to verify parsing (single-line targets, multi-line descriptions, mixed numeric/alphanumeric target codes).

Example (conceptual)

Input fragment:
- "Goal 1. End poverty in all its forms everywhere"
- "Target 1.1 By 2030, eradicate extreme poverty for all people everywhere"
- "Target 1.2 By 2030, reduce at least by half the proportion of men, women and children in poverty"

Output structure:

(?m)^Target\s+(\d+\.[0-9A-Za-z]+)\s+By\s+(\d{4}),\s*(.*)$

1) Suggested schema (normalized)
- Goals: high-level goals (e.g., Goal 4)
- Targets: targets under each goal (e.g., 4.7)
- Indicators: specific indicators under a target (e.g., 4.7.1)
- Countries: country list with ISO code
- DataPoints: measured values for a country, indicator, and year

Tables and relationships:
- Goals 1---many---Targets 1---many---Indicators
- Countries 1---many---DataPoints
- Indicators 1---many---DataPoints

2) DDL (CREATE TABLE statements)

Note: adjust data types for your DBMS (SERIAL in PostgreSQL; AUTO_INCREMENT in MySQL; AUTOINCREMENT in SQLite).

- Goals
  CREATE TABLE goals (
    id SERIAL PRIMARY KEY,
    code VARCHAR(20) NOT NULL UNIQUE,  -- e.g., 'G4' or 'Goal 4'
    title TEXT,
    description TEXT
  );

- Targets
  CREATE TABLE targets (
    id SERIAL PRIMARY KEY,
    goal_id INTEGER NOT NULL,
    code VARCHAR(20) NOT NULL UNIQUE,    -- e.g., '4.7'
    description TEXT,
    FOREIGN KEY (goal_id) REFERENCES goals(id)
  );

- Indicators
  CREATE TABLE indicators (
    id SERIAL PRIMARY KEY,
    target_id INTEGER NOT NULL,
    code VARCHAR(20) NOT NULL UNIQUE,    -- e.g., '4.7.1'
    description TEXT,
    FOREIGN KEY (target_id) REFERENCES targets(id)
  );

- Countries
  CREATE TABLE countries (
    id SERIAL PRIMARY KEY,
    iso_code CHAR(3) NOT NULL UNIQUE,  -- e.g., 'USA', 'BRA'
    name VARCHAR(100) NOT NULL
  );

- DataPoints
  CREATE TABLE data_points (
    id SERIAL PRIMARY KEY,
    country_id INTEGER NOT NULL,
    indicator_id INTEGER NOT NULL,
    year INTEGER NOT NULL,
    value NUMERIC,          -- or DECIMAL(12,4) if you want fixed precision
    unit VARCHAR(20),         -- e.g., 'percent', 'persons', etc.
    FOREIGN KEY (country_id) REFERENCES countries(id),
    FOREIGN KEY (indicator_id) REFERENCES indicators(id),
    UNIQUE (country_id, indicator_id, year)  -- one value per country/indicator/year
  );

  FROM targets t

- Get all indicators for a given target
  SELECT i.code, i.description
  FROM indicators i
  JOIN targets t ON i.target_id = t.id
  WHERE t.code = '4.7';

- Get latest data for a specific country and indicator
  SELECT c.name AS country, i.code AS indicator, d.year, d.value, d.unit
